# Nimbus Boards FAQ (placeholder data — not real)

**Does Nimbus Boards have a mobile app?**
Yes, iOS and Android apps are available with core features (viewing boards,
updating task status, receiving notifications). Time tracking is currently
web-only.

**Can I export my data?**
Yes, all plans support CSV export of tasks and boards. Enterprise plans
also support API-based data export.

**What happens if I exceed my team member limit on the Starter plan?**
You'll be prompted to upgrade to Professional before adding more than 10
members — existing members and data are never affected.

**Is there a way to try Enterprise features before committing?**
Yes, contact sales for an Enterprise trial sandbox with sample data.

**What regions is Nimbus Cloud hosted in?**
US-East and EU-West currently. Additional regions are on the roadmap but
not yet available.
