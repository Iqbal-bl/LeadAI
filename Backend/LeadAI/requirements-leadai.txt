# ===========================================================================
# LeadAI additional requirements

# Install ON TOP of the existing requirements.txt:
#     pip install -r requirements.txt
#     pip install -r LeadAI/requirements-leadai.txt
#
# Most of what LeadAI needs is ALREADY in the outbound requirements.txt and is
# listed here only as a comment so you can see the full dependency picture:
#
#   fastapi, uvicorn, SQLAlchemy, pydantic  -> web + ORM
#   mysqlclient                             -> the shared MySQL engine
#   numpy                                   -> vector scoring
#   httpx                                   -> OpenAI / Exotel HTTP calls
#   PyJWT                                   -> chat widget session tokens
#   python-dotenv                           -> .env loading
#   email-validator                         -> EmailStr validation
#   python-multipart                        -> document upload
#   openai                                  -> (present, though we call the REST
#                                              API through httpx directly)
#
# ---------------------------------------------------------------------------
# REQUIRED additions
# ---------------------------------------------------------------------------
