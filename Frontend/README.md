# LeadAI Platform

A working demo of a multi-tenant AI lead qualification system: each company gets its own
assistant grounded in its own documents, every conversation is scored and summarised, and
leads flow into an admin inbox where they can be assigned to workers who never see the
customer's real contact details.

---

## Run it

```bash
cd frontend
npm install
npm start
```

App on `http://localhost:4200`.
